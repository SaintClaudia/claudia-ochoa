# Player artwork

Generated with the built-in ImageGen tool. Each transparent sheet contains a uniform version on the left and golf attire on the right. The game renders bust crops in player selection and the full-body figures on the course.

Likeness references: [Purdy](https://www.49ers.com/team/players-roster/brock-purdy/), [McCaffrey](https://www.49ers.com/team/players-roster/christian-mccaffrey/), [Kittle](https://www.49ers.com/team/players-roster/george-kittle/). Official headshots were used only as generation references and are not bundled in the game.
