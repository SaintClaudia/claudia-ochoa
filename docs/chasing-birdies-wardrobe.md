# Chasing Birdies wardrobe

The customization concept features an original fictional golfer in three unbranded outfits: ivory polo, forest polo, and navy quarter zip. The portrait assets are `images/birdies-golfer-{ivory,forest,navy}.webp`.

Artwork was generated with ImageGen. The same original character appears in all three looks. These are portfolio concept previews.

The standalone logo has no personal subtitle. The coastal swing scene uses the same original golfer in an ivory outfit. Its new poster is ready; continuous video generation is pending sufficient Runway credits. Source artwork, metadata, device mockups, concept roster, and profile labels use the current identity.
